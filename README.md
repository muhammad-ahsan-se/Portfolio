# Ahsan — Advanced Frontend Portfolio

A premium dark portfolio built with React + Vite.

## What was upgraded
- Real profile photo integrated from `src/assets/ahsan.jpg`
- Scroll reveal animations using IntersectionObserver
- Scroll progress indicator
- Mouse-following ambient glow
- 3D tilt interactions on cards and photo
- Hover micro-interactions for buttons, skills, projects and timeline
- Parallax movement on the profile photo
- Animated orbital accents and marquee
- Active navigation section tracking
- Responsive mobile navigation and layouts
- Reduced-motion support
- Copy cleaned so the portfolio focuses on current skills and work instead of making unsupported future claims

## Run
```bash
npm install
npm run dev
```
